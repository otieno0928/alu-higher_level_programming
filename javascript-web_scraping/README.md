## 📌 Description
This directory contains Node.js scripts designed for file I/O operations and HTTP communication using the `fs` module and the `request` API library. Exercises cover reading/writing files asynchronously, parsing JSON responses from public APIs (SWAPI, JSONPlaceholder), and aggregating endpoint data.

---

## 📂 Tasks & File Breakdown

| File | Description |
| :--- | :--- |
| `0-readme.js` | Reads and prints the contents of a specified file in UTF-8 format. |
| `1-writeme.js` | Writes a string to a specified file path in UTF-8 format. |
| `2-statuscode.js` | Sends a GET request to a URL and displays the resulting HTTP status code. |
| `3-starwars_title.js` | Fetches and prints the Star Wars movie title matching a specified episode ID. |
| `4-starwars_count.js` | Counts how many Star Wars films feature character ID 18 (Wedge Antilles). |
| `5-request_store.js` | Downloads webpage contents from a URL and saves them to a file path. |
| `6-completed_tasks.js` | Computes completed tasks per user ID from the JSONPlaceholder API. |
