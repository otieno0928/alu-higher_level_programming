=============================
How to Use 0-add_integer.py
=============================

This module provides an ``add_integer(a, b=98)`` function.

Usage
=====

Importing the function:
    >>> add_integer = __import__('0-add_integer').add_integer

Passing two positive integers:
    >>> add_integer(1, 2)
    3

Passing a positive and a negative integer:
    >>> add_integer(100, -2)
    98

Passing only one argument (default b=98):
    >>> add_integer(2)
    100

Passing float arguments (should be cast to int):
    >>> add_integer(100.3, -2)
    98

Passing two floats:
    >>> add_integer(2.5, 3.8)
    5
