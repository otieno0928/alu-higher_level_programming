## 📌 Description
This repository contains foundational exercises in **JavaScript (ES6)** executed on **Node.js**. The project introduces essential programming concepts including variable declarations (`const`, `let`), control flow (conditionals and loops), command-line arguments processing via `process.argv`, functions, recursion, objects, and Module Exports.

All code is written to comply strictly with the `semistandard` JavaScript style guide.

---

## 💻 Tech Stack & Tools
* **Language:** JavaScript (ES6 / ECMAScript 2015+)
* **Runtime Environment:** Node.js
* **Linter / Style Checker:** `semistandard`

---

## 📂 File Breakdown & Project Tasks

| File | Description |
| :--- | :--- |
| `0-javascript_is_amazing.js` | Prints `"JavaScript is amazing"` using a `const` variable. |
| `1-multi_languages.js` | Prints 3 lines using `console.log`. |
| `2-arguments.js` | Prints a message based on the number of arguments passed (`process.argv`). |
| `3-value_argument.js` | Prints the first argument passed without using `.length`. |
| `4-concat.js` | Prints two arguments passed in the format `" <arg1> is <arg2> "`. |
| `5-to_integer.js` | Converts the first argument to an integer using `parseInt` and prints it. |
| `6-multi_languages_loop.js` | Prints 3 lines using an array of strings and a loop. |
| `7-multi_c.js` | Prints `"C is fun"` `x` times where `x` is the first argument. |
| `8-square.js` | Prints a square of size `x` using the character `X`. |
| `9-add.js` | Defines a function `add(a, b)` and prints the sum of two integer arguments. |
| `10-factorial.js` | Computes and prints a factorial recursively. |
| `11-second_biggest.js` | Searches and prints the second largest integer in a list of arguments. |
| `12-object.js` | Modifies an object property value from `12` to `89`. |
| `13-add.js` | Exports a function `add(a, b)` visible from outside using `exports.add`. |
